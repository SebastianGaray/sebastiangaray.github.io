# Demo technology filter specification

## Requirements

- Present every demo without featured or ranking language.
- Let visitors filter demos by a single technology or knowledge area without reloading the page.
- Expose the number of matching demos in each option and announce the current result count.
- Keep the control keyboard accessible, bilingual, theme compatible and usable from 20rem wide.
- Describe SketchSense as a convolutional-neural-network demo.
- Link each demo to its current GitHub release.

## Acceptance criteria

- All is selected initially and all three demos are visible.
- Python shows Retail Demand Intelligence and Retail Recommendation Lab.
- Neural networks shows only SketchSense.
- TypeScript shows Retail Recommendation Lab and SketchSense.
- English and Spanish expose equivalent controls and results.
- Automated accessibility and mobile overflow checks remain green.
