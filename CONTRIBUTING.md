# Contributing

Install Node.js 22 or later, run `npm ci`, and keep changes focused. Source code, identifiers,
comments, commit messages, and technical documentation must be written in English. Spanish is
reserved for translated visitor-facing content.

Before opening a pull request, run `npm run format:check`, `npm run check`, `npm test`,
`npm run build`, and `npm run test:e2e`. Never commit credentials, local build output, or dependency
directories.
