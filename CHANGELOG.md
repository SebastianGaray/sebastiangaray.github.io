# Changelog

## 1.0.0 - 2026-08-09

First stable release of Sebastian Garay's portfolio site.

### Included

- Bilingual English and Spanish portfolio content with typed data modules.
- Three linked, end-to-end technical demonstrations with factual limitations.
- Accessible System, Light, and Dark themes with persistent preferences.
- Responsive static Astro output, metadata, sitemap, 404 page, and browser validation.
- GitHub Pages deployment gated by formatting, typing, tests, dependency auditing, and CodeQL.

### Known limitations

- Live demonstrations are hosted separately and may have independent startup or network constraints.
- The site is intentionally static and has no contact form, analytics, or visitor tracking.
