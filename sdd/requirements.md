# Requirements

## Product

- Present Sebastian Garay's professional profile and selected technical demonstrations.
- Provide equivalent English and Spanish routes.
- Support System, Light, and Dark themes with a persisted local preference.
- Organize Home, Demos, About, and Contact as keyboard-accessible views.
- Provide compact animated controls for moving between visible sections.
- Explain external demo availability without hiding hosting limitations.

## Web quality

- Generate a static Astro site for `https://sebastiangaray.github.io/`.
- Publish canonical, alternate-language, Open Graph, favicon, robots, sitemap, and 404 metadata.
- Remain usable on desktop and mobile and respect reduced-motion preferences.
- Avoid tracking, authentication, secrets, paid runtime services, and unnecessary client JavaScript.

## Delivery

- Validate formatting, types, unit behavior, accessibility, production output, and dependency safety.
- Deploy only validated `main` builds with least-privilege GitHub Pages permissions.
- Maintain dependencies with Dependabot and scan JavaScript/TypeScript with CodeQL.
